## 组件结构

- `NaturalVoiceSAPIAdapter/`：原 SAPI 枚举器、普通本地/Azure/Edge，引入已验证 secv2。
- `EdgeGecV2/`：LGPL 算法隔离为可替换 DLL，只有稳定 C ABI 跨模块。
- `HD/`：原 TtsApplication HD 引擎、隔离 helper、SHD3、公开预合成服务及测试。
- `distribution/`：中文统一安装入口、事务式注册、可复现本地审查包及许可文本。
- `Installer/`：保留上游高级设置，包内重命名 VoiceSettings.exe。

HD 保持原生产 CLSID/Token ID，与已接入的 SumatraPDF 兼容。普通音色沿用原枚举器；
HD 用独立引擎、独立 token 与明显后缀。不得按去掉 HD 后的名字合并它们。
HD helper 放在单独 `hd/` 目录，避免加载普通引擎旁的旧版 SDK 同名 DLL。
这是一套统一安装的组件，不要求把两个 COM 引擎强塞入一个 DLL。

## 构建

使用带 ATL、C++ 桌面工具和近期 Windows SDK 的 Visual Studio；本机 VS 2026/v145。
首次克隆时带 `--recurse-submodules`。依赖版本保持各 packages.config 固定值。
先使用 NuGet restore 主适配器及 Installer/packages.config，输出至根目录 packages。
Installer 的 YY-Thunks 统一到 1.1.9，与主项目一致；不包含上游 v0.2.10 的更改。

```powershell
nuget restore NaturalVoiceSAPIAdapter/packages.config -PackagesDirectory packages
nuget restore Installer/packages.config -PackagesDirectory packages
./distribution/Build-Full.ps1
```

主引擎按 vcxproj 直接构建，显式指定 SolutionDir，禁用自动注册。
`EdgeGecV2` 由 ProjectReference 自动构建；sln 也已加入这个项目及配置映射，
完整发行版仍应使用整合脚本，以同时构建 HD 及统一安装入口。
脚本默认构建两位数引擎、64 位隔离 helper、原高级设置及 32 位统一启动器。
输出 `dist/Standalone.zip`；`-SkipBuild` 只重新打包现有构建。
没有复制任何 System32 DLL、模型或 Windows SpeechSynthesizerExtension。

包内 package.json 含每个载荷文件 SHA-256。安装前逐一验证，版本目录以清单哈希命名；
活动读者可保留旧版。安装前快照自己的 NVSA/HD 类、枚举器、四个 HD token 及卸载项，
失败恢复快照；升级保留首次安装前快照，卸载恢复该初始状态。
本地安装器测试使用专用 HKCU 测试树，不能把隔离注册测试当成机器安装成功。

## 客户端约束

标准 SAPI 直接可用；显式预合成由客户端 CoCreateInstance 公开服务。
Prepare 不播放，真实 SpeakStream 才产生 WORD/END。成功入队后须持有 ticket 和 lease
直到 END 或 purge 确认完成，不能立即 Cancel：取消会让已有流的 Read 失败。
客户端的缓存身份须含改写后文本、完整 token、rate、generation；无服务时普通 Speak 一次回退。
详见 `HD/sapi/HdPrepareIntegration.zh-CN.md`。

Sumatra 的生产实现与后端测试参考本机 `C:\src\sumatrapdf\src\SapiSpeechWorker.h`、
`docs\sapi-hd-worker-2026-10-24.md`、`tools\test_sapi_worker.cpp`。
