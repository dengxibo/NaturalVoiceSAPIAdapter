NaturalVoiceSAPIAdapter 独立安装测试版（0.2.9-secv2-hd.1）

安装一次
1. 将整个 ZIP 解压到一个文件夹，双击 Installer.exe，选择“是”。
2. 阅读 licenses 中的适用条款，通过一次 Windows 管理员确认。
3. 完全退出并重新打开朗读软件，在其声音列表中选择所需语音。
安装会同时放置 x64/x86 的联网 secv2、普通本地引擎、HD 引擎及公开预合成服务。
不需要先安装上游，再覆盖多个修复 DLL。默认安装目录为
C:\Program Files\NaturalVoiceSAPIAdapter Full。

模型与系统要求
本包没有微软模型或 Windows 系统 DLL。使用本机已有模型。
HD 路径仅验证 x64 Windows 上的系统扩展 2608.11000.0.0；没有匹配运行环境时，
普通/联网引擎仍可安装，HD 不承诺可用。安装器会检查 Windows 已安装的音色、
C:\TTS 下的子目录，以及之前 HD 适配器所登记的模型位置。模型缺失时先在
Windows 设置中准备需要的自然声音，或者使用自己已有的本地包，再运行安装器。
安装器不自动下载模型，也不复制、移动或删除原模型。

HD 与普通版
两者分别注册、分别选择。HD 名称包含“Natural HD”和“[Local SAPI HD]”，
不会用 HD 覆盖普通 Xiaoxiao 等声音。普通本地语音仍受原版 SDK 的模型兼容性约束。
晓晓/云逸 HD 已验证中英混读；Andrew/Ava 的本地包仅声明英语，不以内部名称
推断它们支持多语言。联网声音需要网络，Azure 需要用户自己的订阅密钥。

声音设置
运行 Installer.exe 选择“否”，打开语音设置，可选本地声音路径、联网声音、
包含语言及 Azure 配置。它们沿用原版用户设置。整合安装与升级由新的 Installer.exe
负责，不要再在高级窗口分别执行旧版安装/卸载按钮。

段落衔接与高亮
任何普通 SAPI 客户端都可以选择语音；显式提前 Prepare 需要客户端接入 sdk 中
的头文件与协议。仅安装本包不会让所有软件自动预合成或保证任意文本无缝。
当前 SumatraPDF 项目已接入生产工作线程；仍需使用包含该改动的读者构建。
逐字事件按模型分词，中文一个词可能含多个字。跨页/OCR 尚无文字时无法提前准备。

升级、回退与卸载
再次运行新版包的 Installer.exe 即升级；版本文件不可变，旧读者不会被强行关闭，
更新后必须重启读者。安装失败会恢复本次操作前的注册。
Windows 设置的“已安装的应用”中卸载本完整版，或运行安装目录 Installer.exe /uninstall。
卸载恢复首次安装前的原有注册；如果当时安装过独立 HD/NVSA，就会恢复它们，
它们的文件需要仍在原处。其他安装器后来接管注册时，本安装器拒绝覆盖它。
模型、用户配置和版本文件保留。关闭所有读者后，可删除本完整版安装目录；
不要删除模型目录或独立适配器目录。

许可证与发行状态
本包为维护者发布的公开测试版，技术验证范围及第三方许可核对分别记录。
上游/HD 的 MIT、secv2 独立 DLL 的 LGPLv3，以及其他依赖的条款分别见 licenses。
EdgeGecV2 的完整对应源码及替换说明已附带。微软 SDK 保持原始二进制，
其 Embedded Speech 组件的公开分发还有额外访问/许可条件；当前没有该批准凭据。
公开测试不代表本项目已核验微软附加分发批准；技术可运行与第三方权利核对是两回事。
安装和使用微软组件须遵守随包的微软条款；本项目不把这些组件或语音模型按 MIT 授权。

维护者资料见 docs，客户端协议见 sdk。故障可在 PowerShell 中运行
Install-Full.ps1 -Action Plan（只检查、不安装），或重新运行安装命令查看错误。
