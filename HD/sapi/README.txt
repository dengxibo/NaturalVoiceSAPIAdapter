本地 SAPI 高清语音桥接器：安装与使用说明

一、用途

为现有 SAPI 5 朗读软件增加以下四个语音：
  晓晓 HD：Microsoft Xiaoxiao (Natural HD) ... [Local SAPI HD]
  云逸 HD：Microsoft Yunyi (Natural HD) ... [Local SAPI HD]
  Andrew HD：Microsoft Andrew (Natural HD) ... [Local SAPI HD]
  Ava HD：Microsoft Ava (Natural HD) ... [Local SAPI HD]

语音名称末尾的 [Local SAPI HD] 是本桥接器新增语音的标记。
支持 64 位和 32 位 SAPI 软件，不需要打开独立播放器。

二、安装

本机已经完成安装，无须重复执行安装步骤。
默认安装目录：C:\Program Files\TtsApplication HD SAPI

需要重新安装时，在完整安装包所在文件夹中打开“管理员 PowerShell”，运行：
  .\Install-System.ps1

出现 Windows 管理员确认时，确认后继续。安装脚本会把程序和模型复制到
上述独立目录，并分别注册 64 位、32 位 SAPI 引擎及四个语音项。

原有 NaturalVoiceSAPIAdapter（NVSA）的文件、配置、语音注册及系统默认
语音不会被替换。无需卸载 NVSA，也无需修改其“Local voice path”。
安装后不要随意移动或删除安装目录；语音注册中保存的是绝对路径。

三、使用

1. 完全退出并重新打开原来的朗读软件，刷新其语音列表。
2. 在语音列表中选择名称末尾带 [Local SAPI HD] 的音色。
3. 中英混合内容优先使用晓晓 HD 或云逸 HD。
4. Andrew HD、Ava HD 已验证可用于英文；本地 Andrew HD 的纯中文测试
   未产生音频，因此不要把它当作中英通用音色。

朗读、停止、语速、音量、按句跳过及保存 WAV 使用原朗读软件自己的控件。
软件支持高亮时，会收到标准 SAPI 词边界、句边界事件；支持口型动画时，
会收到标准口型事件。需要在阅读软件中开启相应显示功能。
如果找不到新语音，先确认软件使用的是 SAPI 5，并重新启动该软件。

四、已验证功能与限制

支持的 SAPI 功能：
  1. 词边界与句边界：向阅读软件报告原文位置、长度及音频位置。
     中文、英文和 & 等 XML 特殊字符均会映射回原文的 UTF-16 位置。
     高亮粒度以模型的分词结果为准，中文词可以包含多个汉字。
  2. 口型事件：使用模型实际返回的口型与时间戳，提供当前口型、
     下一口型及持续时间，不根据文本平均猜测时间。
  3. 书签：支持 SAPI 书签字符串及数字编号，并去除模型的重复通知。
     只包含书签、不包含朗读文字的输入也会触发通知。
  4. 音素覆盖：支持传统 SAPI 音素、通用音素表（UPS）及不附带文字的
     发音插入；按 SAPI 的音素表协商结果转换，不混用中英文音素编号。
     中文传统音素示例为 ni 3 hao 3，英文示例为 h eh l ow。
  5. 按句跳过：正数向前、负数向后、零重读当前句；超出范围时报告
     实际跳过的句数并结束本次朗读。
  6. 朗读中修改语速、音量与清空队列。改变语速时会从当前词重新
     合成后续内容，因此可能重新读一次正在发音的词。
  7. 精确毫秒静音、拼读、常用文本上下文及 SAPI XML 片段处理。
  8. 标准 SAPI 音频播放、WAV 输出，以及 64 位和 32 位软件调用。

词和口型时间戳直接取自本地模型；句边界由 ICU 分句并对齐实际词时间戳。
为保证事件先于对应音频送入 SAPI，每次先缓存当前句，随后输出该句音频；
播放当前句时，后台会预先合成下一句（或下一个静音／音素片段），最多提前
缓存一个片段。更改语速、跳句或停止时，过期的预合成会取消并清理。
长句音频缓存使用临时文件，关闭后自动删除。模型进程会在同一个 SAPI 引擎的
多次朗读调用间复用；引擎释放、取消或发生异常时会清理进程。

预合成只覆盖阅读软件已经提交给 SAPI 的文本。如果软件每次只提交一句，
后续句子尚未提交，就只能复用已加载的模型，不能提前获得下一句的内容。
第一句、过长的句子，以及模型计算跟不上播放的情况仍可能需要等待。

目前只验证了 Windows 系统语音扩展 SpeechSynthesizerExtension 的
2608.11000.0.0 版本；其他版本会被辅助进程拒绝使用。Windows 更新后
如果提示版本未验证，需要更新桥接代码，不能只重新注册语音。

合成使用本地模型，本后端未配置云端语音服务或在线回退。
尚未进行断开网络连接的独立测试，因此不宣称已经验证网络完全隔离。

五、卸载语音注册

完全退出朗读软件，然后在“管理员 PowerShell”中执行：
  & 'C:\Program Files\TtsApplication HD SAPI\Install-HdSapi.ps1' -Scope LocalMachine -Uninstall

此命令只移除本桥接器自己的 COM 类和四个语音项，不会卸载或修改 NVSA。
卸载脚本保留安装文件，避免影响仍在运行的程序。确认相关程序已经退出、
语音注册已经移除后，才可按需删除本桥接器的安装目录。

六、技术说明

SAPI 引擎通过独立辅助进程调用系统 HD 运行时，取得 PCM 音频后交给
SAPI 输出。因此，其他朗读软件可以正常播放或保存 WAV，辅助进程
不会自行重复播放声音。

更新后的程序保存在安装目录的 versions 子目录中，模型仍位于 models。
旧版本文件保留供正在运行的软件使用；完全退出并重开阅读软件后，才会
加载新版本。不要单独移动、删除版本文件夹或模型文件夹。

辅助进程仅在自身创建合成器时，临时重定向自身加载的系统扩展导入数据，
选择 PCM 输出，随后立即恢复。不修改系统文件或其他进程，不提取、
替换模型密钥或许可证，也不把旧 NVSA 的 Speech SDK 加载到 HD 辅助进程。

安装脚本中的 CurrentUser 模式仅用于显式指定语音标识的隔离测试，
不能让语音出现在常规机器级 SAPI 列表中。正常部署应使用上述管理员安装。

七、交给 SumatraPDF 开发者的段落队列接入

请阅读 HdPrepareIntegration.zh-CN.md，并把 HdPrepare.h 交给阅读器项目。
优先在首次 Speak 前调用 HdConfigureSapiQueue(voice, 5000)，继续沿用普通
SAPI 的 A/B/C 异步队列。本设置需要阅读器调用，不会由本适配器强行修改设备。

可选预合成服务提供独立的公开 COM 类，支持能力探测、异步准备、缓存复用、
取消代次及文件／驻留缓存限额。准备过程不播放声音；准备好后使用
HdQueuePrepared 把音频交给普通 SpeakStream，播放边界仍由 SAPI 决定。
阅读器未调用这套可选接口时，仍然走普通 SAPI，不会自动启用跨调用预合成。

purge 之后 SAPI 可能重用流号，客户端需要在自己的 SAPI 线程中完成中止确认、
排空旧通知，并按新代次的 START_INPUT_STREAM 重新接受高亮事件。
后台取消请求现已排空完成帧后复用健康的模型进程；协议不匹配、损坏或超时
时仍会回收重建，避免旧任务的音频或事件混入新请求。
